# Deutlit
// Deutlich is a streamlit based German Learning App. (Still in Prototype phase)
The 4 primary features are going to be : 1) Rapid fire Quiz game for Article Learning.
2) Fill in the blanks exercise to improve Grammar eg. Conjugations according to user prefered level of difficulty.
3) Vocabulary Flash-Card.
4) Exam Prepration Modules with drag and drop features with usage of previous years Papers.
